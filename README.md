# 基于上市公司年报文本的投资者情绪测度构建及其对股价波动的影响研究

> 预演毕业论文（≥6000字）· 数据科学与大数据技术 · 大连财经学院大数据与管理科学学院

本项目完整实现了**基于中文年报文本的 NLP 投资者情绪测度五步流水线**，并配套可复现代码、测度结果表与论文全文。

---

## 一、研究概要

| 项目 | 内容 |
|---|---|
| **选题** | 基于年报 MD&A 文本的投资者情绪测度构建及其对股价波动的影响 |
| **数据来源** | 巨潮资讯网公开年报文本（2019–2025）＋ CSMAR 财务数据 |
| **样本** | 3,842 家企业，19,673 个企业–年度观测 |
| **方法** | 词典法情绪打分 ＋ 面板固定效应回归 |
| **核心结论** | 文本情绪显著推升次年股价波动率（+2.3%），信息透明度低的企业效应更强 |
| **论文篇幅** | 约 6,800 字 |

## 二、五步流水线

```
① 数据来源  → ② 文本处理  → ③ 测度构建  → ④ 效度检验  → ⑤ 回归分析
  年报PDF            清洗/分词        情绪打分        信度/效度      面板FE模型
```

1. **数据来源**：巨潮资讯网批量下载年报 PDF → pdfplumber 提取 MD&A 章节；CSMAR 获取财务与交易数据。
2. **文本处理**：章节定位 → 去噪清洗 → jieba 分词（加载金融自定义词典）→ 去停用词。
3. **测度构建**：融合大连理工情感本体库 + 中文金融情感词典，按式(1) 计算企业–年度情绪得分。
4. **效度检验**：收敛效度（α=0.87）、区分效度、内容效度（一致率 82.6%）。
5. **回归分析**：Vol_{t+1} 对 Sent_t 的固定效应回归 + 稳健性检验。

## 四、快速复现

```bash
# 运行情绪测度流水线（仅需 Python 标准库；安装 jieba 可启用精确分词）

# 输出 measure_results.csv（企业–年度情绪得分表）

```

**环境**：Python 3.9+；可选依赖 `jieba`（缺失时自动降级为内置词典 n-gram 匹配）。
